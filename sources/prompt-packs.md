# Prompt packs

A prompt pack is a folder of notes, not a secret system prompt. Each prompt declares the task, the inputs, and a source issue or file.

If two prompts overlap, the wiki page for `prompts` will show both. That is the point of compile.

## Evaluation prompts

Keep the judge prompt next to the task prompt. Changing one without the other is how evals quietly lie. Tag both `prompts` and `testing`.
