# Wiki export

Compile is a fold: group notes by tag and by wikilink entity, write one page each, write an index with counts. The [[Wiki]] is disposable. Delete `wiki/` and compile again.

Humans browse the wiki. Agents usually query the notes. Both views share the same files.

## Backlinks are the product

A tag page that does not list sources is a table of contents. A tag page that lists `source: seed/wiki-notes.md` is a map you can audit. Prefer the map.
