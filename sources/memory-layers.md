# Memory layers

Treat memory as layers, not as one pile. Episodic notes capture "what happened". Semantic notes capture "what is true". Procedural notes capture "how we do this".

An agent that mixes all three in one blob will retrieve a recipe when you asked for a fact.

## Episodic notes

Write them after a session: who said what, which tool ran, what failed. Timestamp them. They go stale on purpose.

## Semantic notes

Facts that should still be true next month: stack choices, names of systems, constraints. These are the notes [[Provenance]] has to protect, because a wrong semantic note poisons every later plan.
