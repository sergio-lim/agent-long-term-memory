# Decision records for agents

A decision note has four fields in the body: context, options, choice, consequences. The frontmatter already has date and source.

Agents love to re-litigate settled choices. Retrieval should return the record before the model starts a new debate.

## Rejected options

Write the options you did not pick. Future-you will ask "why not embeddings?" and the rejected-option paragraph is the answer. A decision without a rejected path is just a preference.
