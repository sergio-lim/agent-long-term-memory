date: 2026-09-21T11:12:00
tags: [agents, memory]
---
Session memory is the chat transcript: cheap, ordered, and gone when the session ends. Long-term notes survive restarts. Agents remember things across days only if someone copies the durable bits out of the session.

A useful split: keep the last few turns in context, and write anything you would be sad to forget as a markdown note with tags. Retrieval then pulls the long-term layer back into the next session on demand.
