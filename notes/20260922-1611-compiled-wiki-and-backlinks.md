A folder of notes is a haystack. A compiled [[Wiki]] is a map: one page per tag and per wikilink entity, each listing the notes that mention it and the source those notes came from.

Backlinks matter more than pretty pages. When you open `wiki/memory.md` you should see every note tagged memory and be one hop from the original file. The wiki is a view. The notes remain the source of truth.
