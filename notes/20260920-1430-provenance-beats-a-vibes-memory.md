A vector blob that says "the user likes short answers" is a rumor. [[Provenance]] is the habit of keeping the path back to the file, the message, or the page that justified the note.

When an agent remembers without a source, it cannot be audited, it cannot be corrected, and it will eventually gaslight you with a confident guess. Every note in this store carries `source` in frontmatter so a human can open the original.

If you cannot cite it, do not let the agent treat it as fact.
