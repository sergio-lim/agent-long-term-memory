---
Prompts rot when nobody remembers which task they were for. Keep each prompt as a note: the text, the job it solves, and the file or issue that produced it.

Do not let the agent "improve" a prompt in place without a new note. Versioning is provenance. A prompt that cannot point at a source is a style suggestion, not a procedure.
