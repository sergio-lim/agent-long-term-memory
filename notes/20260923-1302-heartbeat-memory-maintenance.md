A heartbeat is a cheap periodic pass: compile the wiki, drop notes that lost their source file, and surface contradictions. It is a [[Tools]] job, not a chat.

Maintenance should be boring. Count notes, count tags, run one canned query, write `wiki/index.md`. If the counts jump or the canned query flips rank, a human should see it. Memory that nobody inspects becomes fiction.
